Python · MySQL · Flask · Data Migration

Music Library Catalog Migration — WPKN 89.5 FM ▾

Problem
A 60-year catalog (dating to 1963) lived in Microsoft Access, assembled from paper cards, dBASE, and Excel over decades. Programmers searched exported spreadsheets on Google Drive. 23,772 digital files on a server drive were uncatalogued entirely.
What I did
Standardized 110,000+ genre tags into 43 controlled vocabulary terms. Catalogued the digital collection from scratch. Migrated 145,086 records into MySQL across 6 tables with referential integrity. Built a Flask search interface with artist, title, genre, style, and local-artists filters — presented as a live proof of concept to the board in April 2026.
Result
99,553 records now searchable in real time. Access and Google Drive spreadsheets retired. Deploying to library.wpkn.org.
